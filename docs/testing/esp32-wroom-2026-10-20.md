- [x] Earlier no-key-response report led to GPIO-polarity and HID-framing fixes; user subsequently confirmed remapping and physical keys work on the current fixture (manual report, 2026-10-25).
- Historical mapping was `5x6`, `kColToRow`, rows `{4,5,12,13,14}`, columns `{15,16,17,18,21,22}`; use the current mapping above.
- One momentary GPIO4–GPIO16 jumper is valid for a single-key bench smoke with the internal column pull-up. Multi-key diode/ghosting acceptance is separate.
